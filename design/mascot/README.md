# Punh Punh: mascot reference

Punh Punh is a short, chubby pencil: a striped yellow body, a cream sharpened cone with a rounded graphite tip on top, and a pink eraser as its base. Usage rules live in the product blueprint (§11 Mascot: Punh Punh).

## Character colours

| Part | Colour |
|----|----|
| Pencil yellow (body) | `#F7C83A` |
| Golden stripes | `#E5A923` |
| Eraser pink | `#F28FAA` |
| Cream (cone) | `#F6E6C8` |
| Graphite (tip, outlines) | `#3B3A40` |
| Soft sky background | `#C9DDE8` |

Pencil yellow is the same HopFlows yellow used for the hero tile in the Soft Bento design system.

## Poses

Each pose comes in two facings, left and right (files `1` and `2`).

| File | Pose | Use |
