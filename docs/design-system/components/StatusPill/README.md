# StatusPill

A card-coloured pill with an 8px dot and a word that says how a piece of work is going.

- Tones: `on-track`, `at-risk`, `off-track`, and `urgent` (carbon fill, no dot).
- The word is always shown; colour never carries the meaning alone.
- Sits on `ground` or `inset`; on a white card, use it as is (the pill is the card colour, so it reads as text plus dot).
