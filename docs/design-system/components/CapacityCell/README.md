# CapacityCell

A 52px rounded cell that shows how full someone's week is, as a fill plus a word.

- States, light to heavy: `room`, `balanced`, `buffer` ("Using buffer"), `overloaded`; plus `away` (hatched).
- Optional `hours` adds a mono line such as `31h / 32h`.
- Use in rows of five (a week) or in a team list's right column at a fixed 104px width.
