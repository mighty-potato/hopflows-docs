# Button

Pill-shaped action button: carbon primary, card or inset secondary, Hop-yellow accent and a text-only ghost.

- One `primary` per group; pair it with `secondary` (on ground) or `inset` (inside a card).
- `accent` only for celebratory confirmations ("All clear") and the capture `+`; never next to a yellow tile.
- `md` (48px) by default; `sm` (44px) inside dense cards.
- Labels are verbs or short answers: Start, Done, Need help, Accept, Later.
- Icon-only buttons need an `aria-label`.
