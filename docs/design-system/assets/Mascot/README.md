# Mascot

Punh Punh, the HopFlows pencil. Three poses, each facing left and right; pick the side that faces into the screen.

| File | Pose | Use |
|---|---|---|
| `punh-punh-welcome.png`, `punh-punh-welcome-right.png` | Holds a blank note | Onboarding, empty states ("Nothing here yet") |
| `punh-punh-wave.png`, `punh-punh-wave-right.png` | Waves | Greetings, first sign-in, small avatar beside the streak (44–52px, `radius-md`) |
| `punh-punh-done.png`, `punh-punh-done-right.png` | Holds a checked note | Completion moment and "All clear"; sits in the yellow hero tile on Today (150–190px, bleeding off the bottom-right corner) |

The art is on a sky background (`#C9DDE8`, the `sky` token in Light), so it sits cleanly on `sky` tiles and as a cropped corner on the yellow hero tile. One Punh Punh per screen, always with alt text, never recoloured, never on urgent alerts, Need help, risk flags, handovers or confidential items.

Still to make for the MVP: celebrate, thinking, calm and resting poses, lightweight vector animations, a sticker set and the bot avatar.
